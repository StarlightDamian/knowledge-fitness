# 双向钢人论证：健身百科，还是可审计的决策工具？

## 1. 把真正的问题说完整

要解决的不是“网上缺少健身知识”，而是普通人面对太多互相冲突的知识时，难以回答一个很具体的问题：**以我现在的目标、能力、健康限制、时间和实际可用器材，下一步做什么，为什么，如何判断是否值得继续？**

因此这个项目至少有四个不同任务。知识地图负责防遗漏；证据系统负责说明适用条件和不确定性；计划与器材系统负责把原则转成可执行选项；量化反馈负责观察变化而不制造错误解释。GitHub与网页不是第五套知识，而是让上述内容低成本公开、搜索、纠错、翻译和长期维护的载体。

成功不应该定义成“收录最多名词”，而应当定义成：新手能快速找到可理解的下一步；器材不足不会被假定拥有；特殊情况不会收到冒进处方；来源更新后能定位受影响条目；新增器材不需要改写整个网站。

本项目把“增肌/减脂”当作最直接的两个入口，但不把它们当作全部知识的两个互斥抽屉。训练剂量、蛋白质、睡眠、动作技能与数据解释需要复用，而不是复制两遍。WHO同时保留有氧与肌力活动；并行训练的综述也不能支持“增肌必须删除有氧”这种普遍命题。[WHO 2020](https://bjsm.bmj.com/content/54/24/1451)；[Schumann等2022](https://pubmed.ncbi.nlm.nih.gov/34757594/)。

## 2. 支持当前方向的最强论证

### 把知识变成可以执行的结构，比再写一本长书更有用

两个参考项目最值得借鉴的是低阅读门槛、短结论、来源可见、离线与搜索；它们让读者不必先成为专家才能行动。本项目沿用这种产品方向，而不是复制文字或盲目继承许可。来源：[HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)、[离线阅读项目](https://github.com/cdyforever/how-to-live-better)。

同样的训练原则可以通过不同器材落实。如果把器材结构、可完成动作、使用限制和适用场景标准化，用户就能发现自己不必为了某种看起来“更专业”的器材才开始。ACSM 2026的更新强调抗阻方式的多样性与持续参与，而不是要求所有人遵循唯一复杂训练系统。[ACSM官方更新](https://acsm.org/resistance-training-guidelines-update-2026/)。

### 横向比较可以降低“广告替代决策”的风险

用户真正需要的往往不是“机器A比机器B强10分”，而是：A是否需要安装锚点，B是否受身高适配影响，自己能否调节重量，是否有需要避开的夹点，能否在现实空间里完成该动作。统一字段让这些限制显性化，而不是被外观和品牌热度掩盖。

### 可解释推荐比黑箱个性化更适合第一版

系统可以先执行安全和资源限制，再在可行集合里推荐少量模板，并展示未入选原因。这样每一个结果都能用测试复现。开源贡献者可以修复一个错误的器材映射，而不必重新训练一个模型，也不必把读者健康信息发送到第三方服务。

### 开源和结构化证据有维护优势

稳定ID将论点、来源、器材、动作、计划关联起来。文章撤回、指南更新或翻译纠错时，可以找到受影响页面。这种价值不来自“GitHub自动保证正确”，而来自变更差异、审阅记录和回归测试可以公开检查。

## 3. 反对当前方向的最强论证

### “健身领域完整MECE树”本身可能是错误模型

哑铃是器材，卧推是动作，超级组是组织方法，增肌是目标，孕期是状态，肩痛是症状。它们不是同级概念。强行放在同一棵树里会产生重复、遗漏和错误继承：例如“归入康复器材”并不意味着对所有伤病安全。

更合理的要求是**每一轴内部有一致定义，跨轴可以交叉引用**。对象可以有多个作用，但只有一个编辑选定的主归属；主归属是治理约定，不是自然界唯一真分类。没有完成外部样本验证前，不能用“类别齐全”替代“市场覆盖”。

### 95%的分母还没有定义

95%可能是健身房设备台数、用户使用次数、器材类型、被问到的问题，或购买市场份额。每一种分母都会导向不同目录。140个条目不能自动推出95%；把腕带、哑铃和大型综合训练机都计作一个条目，也不能据此解释使用覆盖率。

如果按台数统计，大量跑步机可能掩盖少见但重要的康复或无障碍设施缺失。如果按类型统计，罕见附件和普遍使用的哑铃又可能获得相同权重。因此必须同时报告口径、地域、场景、样本日期、未知项与分层结果。

### 横向比较不能被偷换成增肌/减脂总排名

器材、动作、负荷、训练量、接近力竭程度和执行频率共同决定训练刺激。不存在一个脱离使用方式仍然通用的“器材增肌分”。自由重量与器械的比较综述没有建立普适增肌冠军；其无显著差异也不等于已经证明所有情境等效。[Haugen等2023](https://pubmed.ncbi.nlm.nih.gov/37582807/)。

因此，要求所有器材都显示同一个“效果分”会诱导伪精确。体脂秤、训练凳、泡沫轴与深蹲机的任务不同，很多结局应该标记“不适用”，不是强行填数。

### 两个权威引用仍可能是单一证据链

同一篇文章在PubMed和期刊官网出现，是一个文档；两篇综述共享原始试验，不是两次独立重复；WHO与CDC的建议一致，也不代表产生了两个独立干预试验。期刊声望不能弥补人群、结局、时间尺度或剂量不匹配。

对“一个数字”的校验必须落到同一个指标、单位、人群与结局上。例如蛋白质荟萃回归中的平均拐点，不能变成每个人不可超过的精确上限，也不能自动套用于肾病人群。[Morton等2018](https://pubmed.ncbi.nlm.nih.gov/28698222/)；[ISSN 2017](https://pubmed.ncbi.nlm.nih.gov/28642676/)。

### 简短搜索无法代替健康筛查或现场教学

“膝盖不舒服，练腿”不足以识别诊断、手术阶段、负重限制、药物影响与危险表现。为了追求搜索快而自动给训练处方，会把信息缺失误当作健康确认。反过来，过度保守也会阻止本来可以安全活动的人；这是产品需要明确承认的取舍，而不是隐藏在免责声明里。

### 多语言和生成图会扩大错误的传播范围

多语言不是只翻导航：否定词、剂量、频率、禁忌条件和就医提示都可能因翻译改变含义。未经审核的动作图也可能画出错误握法、关节位置或器材连接。出版这些内容应当有独立校核，不应用“生成成功”代替“教学正确”。

## 4. 双方真正的分歧与会改变结论的变量

| 关键变量 | 取值不同会改变什么 | 本版决策 |
|---|---|---|
| 服务对象 | 健康新手与术后患者需要完全不同的安全体系 | 标准模板限定健康成人教育范围；特殊状态分流 |
| 正确性的定义 | 结构自洽、来源对应、独立专家审核、真实临床效果是不同层级 | 各层状态分开，不把测试通过当临床审核 |
| 覆盖率分母 | 台数、类型、使用频次和问答任务得出不同优先级 | 提供抽样工具；未采样不显示95%已达成 |
| 推荐的责任 | 检索教育模板与开具个体处方不是同一产品 | 硬约束匹配与原因说明，不生成医疗处方 |
| 证据粒度 | 训练类别证据不能认证具体机器 | 明确类级证据与型号级待核查 |
| 翻译质量要求 | 一次性铺满语言与确保每条高风险信息一致存在冲突 | 正文中英完整；其余导航可用、回退显式 |
| 内容维护资源 | 无审校人力不能承诺永久“最新最权威” | 明确核对日期、变更流程和待审状态 |
| 成果指标 | 页数/引用数可以很大，但不意味着用户更会选择 | 优先可行性、理解成本、误推荐和纠错成本 |

核心分歧不是“百科还是网站”，而是**是否愿意牺牲表面上的全覆盖与确定答案，换取有边界的真实可用性**。本版选择后者，同时把目录和数据格式做成可继续扩展的结构。

## 5. 收敛后的项目定义

第一层是通识和证据；第二层是器材与动作；第三层是方法和模板；第四层是人群与安全适配；第五层是指标反馈。增肌与减脂只是进入这些共享层的不同阅读路径。

“权威、简洁、有效”被拆成可以检查的条件：结论对应来源；来源作用可读；模板能在勾选器材与时间内找到；不存在可行模板时说没有；不生成未经授权的医疗处方；比较不填假数；增加器材只改数据；翻译与覆盖率状态不造假。

交付版本已经实现这些网页和代码能力，但**没有把专家签署、全部语言正文、全市场覆盖与真实托管验收伪装为已完成**。它是一份可运行、可维护、可公开接受审阅的首版，而不是一张永远不会过期的“健身真理证书”。
