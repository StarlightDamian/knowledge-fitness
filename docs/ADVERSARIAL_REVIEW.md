# 对抗式审核：器材覆盖与训练合理性

审核日期：2026-09-29。范围：器材目录、动作、12份计划、14种方法、知识与安全分流、实际器材匹配，以及首次 GitHub 交付说明。采用目录核对、官方资料对照、反例复现和软件回归；未开展场地抽样、真人训练试验或独立持证专家签署。

## 结论

**常见商业健身房与家庭基础训练的大类已基本覆盖；户外公共设施仍不完整，不能宣称覆盖全部主流器材或达到95%。训练框架总体合理，但原版有进阶、单侧剂量和器材匹配问题，本次已修正。**

目录从136条增至140条，含74条抗阻、18条有氧、11条体能、24条支撑、6条恢复和7条测量工具。这是编辑条目数，不是140种互不重叠的训练机器。完整功能组矩阵、结构来源与采样口径见[覆盖审核](COVERAGE.md)。

## 训练方式为什么总体合理

1. **抗阻起点可执行。** 新手模板通常每动作2组、每周2–3天，设置休息与余力，没有要求每组力竭。ACSM强调持续参与、主要肌群规律训练，并认可多种抗阻工具；本站具体组次与余力是编辑安排，不能称为逐项得到指南认证。[ACSM 2026官方说明](https://acsm.org/resistance-training-guidelines-update-2026/)
2. **增肌和减脂的安排可以共存。** 减脂入口保留抗阻与恢复提示，有氧独立记录；没有以出汗或某台机器推定减脂效率，也不生成个人热量缺口处方。[CDC成人活动建议](https://www.cdc.gov/physical-activity-basics/guidelines/adults.html)
3. **入门量没有冒充完整周目标。** 纯骑行模板每周60分钟是起点，部分计划的有氧量仍需另行积累；WHO同时强调少量活动有价值、减少久坐及肌力活动。模板已说明缺项，不能把几次短课等同于覆盖完整公共健康建议。[WHO身体活动说明](https://www.who.int/news-room/fact-sheets/detail/physical-activity)
4. **方法不是效果排名。** 14种方法以组织训练的用途和限制呈现，没有承诺高级技巧优于基础训练；自动匹配保留健康、经验、时间及器材约束。

## 仍然不能确认的事项

- 户外转腰器、太极轮、横梯和自重划船等类型尚未收录；品牌型号、竞技专项和临床康复设备未做穷举。
- 未定义并完成市场抽样，`measuredEquipmentCoverage` 仍为 `null`。
- 每次训练分钟数是编辑预算，未由真实学员计时；排队、动作学习和个体休息可能使训练超时，不应压缩必要休息来追赶模板。
- 所有模板均未作为整套干预接受临床试验，也未获得独立教练或临床人员签署；简要动作提示不能替代现场教学。
- 症状文本识别存在漏判和误报。结构化筛查及停止条件保留，公开阅读不等于获得训练许可。

## 完成证据

- 原版在本机通过143项测试，但仍存在上表内容问题，说明结构校验不能替代专业内容核对。
- 新增回归先复现组合机漏匹配、单侧次数、纯有氧进阶和徒手进阶问题，再验证修正；另覆盖挂片条件。
