# 安全、人群适配与损伤康复边界

这是产品范围说明和教育资料，不构成诊断。网站不能排除急症，不能根据一个疼痛部位决定诊断，也不能替代现场动作教学。

## 安全不是免责声明，而是匹配前置条件

严重/持续胸痛或伴随危险表现、晕厥、明显神经异常等触发停止自动匹配并提示联系当地急救/医疗系统。腰痛合并新的大小便控制异常、会阴感觉异常等需要特别重视。警示列表不穷尽，未匹配到关键词不表示安全。[NHS胸痛](https://www.nhs.uk/symptoms/chest-pain/)；[NHS背痛](https://www.nhs.uk/conditions/back-pain/)。

表单必须回答紧急症状和影响训练的健康限制；“不知道/未填写”不当作健康。疼痛、术后、慢病、运动相关用药、孕产期、活动受限或进食障碍风险进入适配路径，**不自动放宽为标准增肌或减脂模板**。

标准模板的自动匹配对象是18–64岁、无已知限制的成人教育场景；65岁以上和未成年人保留教育入口，不自动匹配本版成人模板。65岁只是本产品的开发范围边界，绝不是“应停止训练”的医学结论。WHO明确包含老年人与残障人群的活动建议。[WHO 2020](https://bjsm.bmj.com/content/54/24/1451)。

## “损伤康复”至少要拆成六个任务

| 阶段 | 需要知道什么 | 本版提供什么 / 不提供什么 |
|---|---|---|
| 识别异常 | 发生机制、危险表现、功能丧失 | 官方警示边界；不能远程确定是否只是酸痛 |
| 明确问题 | 诊断、受累组织、术式、合并病、负重限制 | 说明为什么需要专业评估；不生成诊断 |
| 控制初期负担 | 当前症状、保护要求、日常功能 | 一般教育；不规定所有损伤统一停练几天 |
| 恢复活动与能力 | 活动范围、力量、平衡、耐受与进展 | 指向个体化适配；无通用机器/组次处方 |
| 返回训练或运动 | 目标任务、复测结果、心理准备、环境 | 提醒按任务恢复；不凭体重或痛感单指标放行 |
| 长期管理 | 负担调整、复发风险、依从性 | 记录与讨论支持；不预测个人复发率 |

慢性原发性腰痛指南不能直接套到创伤、感染、肿瘤相关、术后或神经压迫等不同情况。[WHO 2023腰痛指南说明](https://www.who.int/news/item/07-12-2023-who-releases-guidelines-on-chronic-low-back-pain)。骨关节炎指南也不能代表所有关节疼痛。[ACR/AF指南](https://pubmed.ncbi.nlm.nih.gov/31908149/)。

## 特殊人群不是单个标签

孕产期要考虑阶段、并发症与产科意见；2型糖尿病要考虑用药、低血糖及并发症；心血管/肾脏疾病不能直接应用一般营养乘法；残障/活动受限需要实际通道、转移、座椅、控制方式和任务调整。页面提供的是这些问题的阅读入口，不是已解决它们的个体方案。[ACOG 2020](https://pubmed.ncbi.nlm.nih.gov/32217980/)；[ACSM 2型糖尿病共识](https://pubmed.ncbi.nlm.nih.gov/35029593/)。

## 不允许的自动输出

未知诊断下的康复组次、孕期减脂处方、未成年热量赤字、心率药物使用者的固定靶心率、仅凭年龄放行高强度、DIY血流限制袖带压力、承诺某器械治愈腰痛、把BMI或手表分数当医学诊断。

## 图示与现场使用

13张SVG用于类别识别与流程说明，不是具体型号实物图或经教练校核的动作解剖图。单个动作只有简短提示；新手仍需学习正确设置、安全退出、调节承重与保护要求。提供参考图不等于验证了教学正确性。

设备主类证据不认证具体品牌型号。使用前核对原厂手册、限载、锁销、锚点、磨损和安全空间；公共户外设备的维护与尺寸适配不能默认合格。
