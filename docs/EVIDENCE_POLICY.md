# 证据治理政策

## 本版到底做了哪种审核

已经做的是来源身份核对、公开可访问摘要/官方正文的案头阅读、同一论点的来源角色比较、措辞与适用范围核对，以及程序化引用完整性校验。32个条目是**去重文档数**，含研究、指南、官方健康资料及少量厂商结构资料，不是32项独立RCT。

尚未完成：所有原始试验全文逐项偏倚评估、完整独立复算、持证医学/运动科学专家签署、多语言临床审校、所有型号实物与说明书验证、全部文献的系统性撤稿数据库扫描。未完成的工作不得在网页上暗示完成。

## 最小可追溯单元是论点，不是文章尾部的链接堆

每个知识条目保存结论、行动建议、适用范围、来源ID、逐来源作用、审核标签、核对日期。来源记录保存题名、年份、DOI或规范URL、机构/期刊、证据类型、可访问层级、适用人群、重叠提醒与审核状态。

同一文章的PubMed、PMC、期刊网页按DOI/规范文档ID去重。两个期刊域名不等于两个独立证据链；两篇综述可能共享试验；机构的科普摘要和其原始指南不计两份独立实验支持。

## 不同来源能证明不同的事

| 来源 | 可以支持 | 不可以直接支持 |
|---|---|---|
| 人群/疾病指南 | 适用对象、照护框架、风险边界、公共建议 | 某个陌生用户适合某台器材 |
| 系统综述 / 荟萃分析 | 特定人群、干预、对照与结局的平均证据 | 全部人群效果相同；所有器材等效 |
| 单项试验 | 该样本、剂量、结局与期限下的观察 | 万能阈值；永久有效；所有品牌 |
| 方法/机制研究 | 解释某个过程或测量问题 | 用代理指标直接替代长期临床或功能结局 |
| 厂商目录 / 手册 | 产品结构、使用设置、规格与维护 | 优于别的产品的健康效果，除非另有合格比较证据 |
| 编辑编排 | 默认界面、模板安排、展示窗口与排序 | 被宣称为研究证明的个人最优方案 |

本版每张知识卡至少关联两个不同文档，但**并非每个子句都有两项直接独立研究**。当第二来源只是背景、共享综述或安全边界，审计字段明确指出。保留这种说明，比冒充统一“A级证据”更可靠。

## 审阅流程

提出精确论点 → 定义人群/干预/比较/结局/时间 → 检索原始指南与研究 → 核对DOI和更新/勘误 → 抽取支持范围及不支持范围 → 检查研究重叠 → 写出不夸大的结论 → 将行动建议与研究原结论分开 → 专业审阅 → 翻译对照 → 测试与发布。

同一来源出现矛盾，先检查目标人群、训练经验、总量是否匹配、测试特异性、效果大小与置信区间，而不是简单按新旧或期刊影响因子投票。统计上“无显著差异”不能被写为“完全一样”。

## 更新与撤回

资料变化通过PR处理，保留原ID和变更原因。影响安全、剂量、禁忌或疾病适配的改动，需要独立合格审阅后才可升级为已审状态。自动流程只做校验和构建，**不自动抓取并发布新的医疗结论**。

发现可能有害或引用错配的条目，应先限制对应自动推荐并标注待复核，再处理措辞和证据。撤回条目保留迁移/撤回记录，避免外链静默指向另一含义。

建议维护者定期人工复查核心指南、更新/勘误及重要综述，并在每次发布时填写审核时间；这里没有替维护者创建定时任务，也不承诺无人值守即可保持医学正确。

## 审阅状态

`editorial-classification`：类型与结构的编辑归纳；`desk-reviewed`：案头核对；`expert sign-off pending`：独立专家未签署。只有真实审阅人同意公开其适用资质与审阅记录，才允许新增 `expert-reviewed` 状态。不允许程序自行升级医学可信度。

本项目不冒用GRADE：GRADE需要结果级偏倚、不一致性、间接性、不精确性及发表偏倚评估，仅靠来源种类和链接数不足以完成。

## 实际勘误核对示例

BFR 2019综述的[公开勘误](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2019.01332/full)补充了相关商业培训机构的利益关联，并删除“Position Stand”的表述。作者表示科学结论未变。本项目按专家综述收录、记录该限制，不将它宣传为学会正式指南，也不提供自行加压的操作处方。该例说明，出处的期刊名称不能替代对来源身份、更新和利益冲突的核对。
