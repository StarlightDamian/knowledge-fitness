# 分类体系：按对象分层，按属性交叉

本文件是本项目的编辑分类约定，不宣称是唯一行业标准。MECE要求在**同一分类轴**中定义边界；它不要求同一器材只能有一个用途。

## 1. 六种对象，不放进同一层目录

| 对象 | 回答的问题 | 例子 | 存储 |
|---|---|---|---|
| 通识 / 论点 | 为什么，适用谁，证据是什么 | 频率、蛋白质、睡眠、测量误差 | knowledge.json + sources.json |
| 器材 | 用什么、有什么结构条件 | 哑铃、腿举机、弹力带 | equipment/*.json |
| 动作 | 做什么身体任务 | 蹲、划船、卧推 | exercises.json |
| 方法 | 怎么组织刺激 | 直组、循环、超级组、间歇 | methods.json |
| 计划 | 何时、做哪些动作、多少剂量 | 每周2天哑铃全身 | plans.json |
| 人群 / 状态 | 哪些信息改变适配或需要分流 | 孕产期、伤后、老年、慢病 | populations.json + safetyGate |

目标不是器材类别。“增肌”“减脂”用于入口与计划过滤；健康、力量、耐力、平衡和功能可作为未来扩展目标。

## 2. 器材主归属：有顺序的判定规则

先判断条目的**主要用途角色**，再按训练设备的结构分组。分类判定应保存在PR说明里。没有唯一自然归属的多功能设备，以该条目的主要编辑定义为准；其他能力用标签，不复制ID。

1. 测量或监测为主 → `measurement`；恢复/活动度辅助为主 → `recovery`；安装、支撑、保护、连接附件为主 → `support`。
2. 以连续周期性心肺活动为主 → `cardio`。以投、跳、搬运、打击等体能任务为主要产品用途 → `conditioning`。因此药球可列体能类，不因为它也能被举起来而重复列自由负重。
3. 剩余以抗阻任务为主的设备：飞轮/气动/液压主阻力 → `special`；弹性体/弹簧主阻力 → `elastic`；多用途、可重设出力方向的滑轮系统 → `cable`；专用插片配重动作站 → `stack`；挂片且主运动受杠杆/导轨导向 → `plate`；以承托/悬挂使用者自重为主 → `body`；其余由使用者自主控制外部质量轨迹 → `free`。
4. 综合训练机以多用途系统登记；具体使用时展开动作与器材条件。新增无法解释的结构先提分类Issue，不偷偷归到“其他”后声称已经全面。

| 主类 | 典型对象 | 容易混淆的边界 |
|---|---|---|
| 自由负重 | 固定/可调哑铃、直杆/曲杆/六角杠、壶铃、杠铃片 | 杠铃片可直接持握或为兼容设备加载；训练凳、架和卡箍属于辅助 |
| 挂片导向 | 史密斯、哈克、倒蹬、钟摆蹲、挂片推拉 | 挂了片不代表自由路径；导轨和杠杆会改变任务 |
| 插片专用 | 推胸、腿屈伸、腿弯举、髋外展/内收 | 固定用途的高位下拉/划船仍可归专用站，不因存在钢索就一律归龙门架 |
| 多用途滑轮 | 高低滑轮塔、龙门架、双滑轮、综合站 | 可配置性是关键；某次动作可以只用于一个肌群 |
| 弹性/弹簧 | 长环带、迷你带、管带、弹簧拉力器、普拉提环、Reformer | 普拉提环靠弹性形变产生阻力，不是悬挂吊环；弹簧核心床不等于所有普拉提训练 |
| 自重支撑/悬挂 | 引体杆、双杠、吊环、悬挂带、肘垫举腿架 | 举腿架以移动身体自重为主；引体杆和深蹲架可共享部件，但按主要登记对象区分 |
| 周期有氧 | 跑步机、走步机、车、划船机、楼梯机、上肢功率车 | 划船机与力量划船机不是同一用途；阻尼档不是运动强度的通用刻度 |
| 体能工具 | 战绳、跳箱、跳绳、雪橇、药球、沙袋 | 学习要求与适配取决于动作，不因为“功能性”就对所有人更好 |
| 支撑/辅助 | 凳、架、垫、附件、腰带、护腕 | 牧师凳只支撑上臂，需另配负重；单件辅助工具不评“增肌效果分” |
| 恢复/活动度 | 泡沫轴、按摩球、按摩棒、拉伸带 | 不等于诊断工具或组织修复装置 |
| 测量监测 | 秤、围度尺、心率带、手表、握力计 | 设备显示精度、真实准确度和临床解释不同 |
| 特殊阻力 | 飞轮、气动、液压 | 没有同一通用重量标尺；不预设优于传统器材 |

## 3. 主类之外的正交属性

`patterns` 表示动作方向/任务；`regions` 表示主要区域；`role` 表示抗阻、有氧、体能、支撑、恢复或测量角色；`settings` 表示家中、健身房、户外；`path` 表示自主、导向、周期、辅助、测量；`learning` 与 `footprint` 是编辑的定性档位。

这些标签允许多选。身体部位不是精准肌肉激活图；“胸部”不表示只训练胸部。“学习较低”不表示无风险。“占地小”不包含每个动作需要的全部活动安全空间。

未来可增加独立字段：阻力曲线、关节动作、出力方向、单侧/双侧、开放/闭合链、负荷增量、身高适配、允许负载、维护项、噪声、转移通道和具体型号手册。**没有型号来源时不要填精确尺寸、承重、价格或风险数值。**

## 4. 通识地图与深度边界

| 知识层 | 子维度 | 本版定位 |
|---|---|---|
| 目标与基础 | 适应、特异性、目标冲突、依从性 | 短卡与模板依据 |
| 抗阻与有氧 | 频率、强度、量、动作顺序、休息、进阶、并行安排 | 可执行入门模板；高级竞技周期不自动开具 |
| 营养与能量 | 饮食习惯、蛋白、能量平衡、补充剂边界 | 原则教育；不生成疾病膳食或热量赤字 |
| 测量与反馈 | 体重、围度、体成分误差、表现、负荷、主观感受 | 本地量化；不输出理想体脂/疾病判定 |
| 疲劳与恢复 | 睡眠、酸痛、负担、压力、恢复工具 | 自我观察与安全边界；不预测受伤 |
| 损伤与康复 | 警示、诊断差异、伤后返回、慢性腰痛、关节问题 | 教育与分流；不替代按病种/术式的临床路径 |
| 人群与环境 | 年龄、孕产期、慢病、残障、训练史、场景 | 交叉适配，不把症状当诊断 |

这是**领域地图的覆盖**，不等于所有子领域已有同等数量的百科文章。专项竞技、药物、临床康复协议、极端环境训练与品牌型号工程参数都需要独立证据包，不能通过补一个标签宣告完成。
